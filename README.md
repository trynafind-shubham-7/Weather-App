# Weather App 🌤️

A modern and responsive weather application built with **React**, **OpenWeatherMap API**, and **GSAP animations**. Search for any city to view its current weather conditions with a dynamic visual experience.

## ✨ Features

* 🌍 Search weather by city
* 🌡️ Temperature, feels-like, minimum & maximum temperature
* 💧 Humidity information
* 🎨 Dynamic backgrounds based on weather conditions
* ⚡ Smooth GSAP animations and transitions
* 📱 Responsive interface

## 🛠️ Tech Stack

* **React.js**
* **JavaScript**
* **CSS**
* **OpenWeatherMap API**
* **GSAP**

## 🚀 Run Locally

```bash
git clone <your-repository-url>
cd Weather-App
npm install
npm run dev
```

## 📌 Overview

This project demonstrates **API integration, React state management, component-based development, responsive UI design, and animation using GSAP**.
